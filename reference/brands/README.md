# Бібліотека брендів і атрибутів за нішами

Бренди залежать від ніші й не мають кінця, одним списком «на все» їх не покрити. Тому:

1. **Джерело - дані, а не пам'ять.** Беріть бренди й фільтри зі структури конкурентів:
   `python scripts/brands_from_competitor.py "<url категорії конкурента>"` → кандидати з фільтрів.
2. **Страховка - аудит бази.** Після першого проходу: `python scripts/cluster_gaps.py <ядро.xlsx>` ловить бренди й атрибути, що осіли в catch-all кластері.
3. **Накопичення.** Фінальний список ніші зберігайте сюди: `reference/brands/<ніша>.txt`, наступного разу не доведеться збирати заново.

Формат файлу: один рядок на бренд - `Канонічна назва = alias1|alias2|alias3` (аліаси - regex-фрагменти для is_minus і кластеризатора з урахуванням RU, UA і латиниці). Межі слова обов'язкові (`jack`≠«panama jack»).

Готові ніші: `caps.txt` (кепки), `tablets.txt` (бренди планшетів для чохлів).

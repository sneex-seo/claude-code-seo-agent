# claude-code-seo-agent

Віртуальний SEO-спеціаліст рівня джун/мідл для Claude Code. Відкриваєте папку в Claude Code і ставите задачі в чаті, як співробітнику: «заведи проєкт», «збери семантику», «розбери GSC», «спланий тиждень». Ви - тімлід, агент - виконавець.

Це не окрема програма, а набір інструкцій і скриптів для Claude Code:
- `CLAUDE.md` - роль, правила і стандарти здачі;
- `.claude/skills/` - 13 скілів, кожен описує одну задачу покроково, з чек-листом перед здачею;
- `scripts/` - розрахунки, які не можна довіряти моделі «на око»: API Serpstat і DataForSEO, структура конкурентів, покриття ядра, дублі, ризик-скор посилань, аналіз GSC, анкор-план;
- `reference/` - мінус-листи (Росія й окуповані території, маркетплейси, міста UA), маркери інфо-інтенту, бренди за нішами.

Три правила, заради яких агент і писався:
- **Дані, а не здогадки.** Частотності, позиції, трафік - лише з API, вивантажень або краулу. Немає даних - агент каже, чого бракує, а не вигадує.
- **Арифметика - скриптами.** Суми, покриття, дублі, баланс «вхід = кластери + інфо + видалено» рахує Python, а не модель.
- **Уроки після кожної правки.** Ваше зауваження на прийманні агент одразу записує в скіл або в `lessons.md` проєкту і наступного разу враховує.

Приклад роботи - семантика категорії «зарядні станції». На вході 6 конкурентів і сіди: агент розібрав, які фільтри в конкурентів є і які з них ранжуються, зібрав їхні ключі й свої, разом 15 480. Результат - 8 140 ключів на 257 сторінках чотирьох рівнів (база → бренд → серія → модель: «EcoFlow > Delta > Delta 2»; база → призначення → потужність: «Для квартири > 3 кВт»), 646 інформаційних запитів у 39 темах статей з прикладами статей із видачі, 6 694 видалено з причиною для кожного. Кожну детальну сторінку перевірено видачею Google, кожен ключ - другою моделлю (ChatGPT). Сторінка з розбором і xlsx: https://oleksiimatuznyi.com/lab/seo-agent/

## Як агент перевіряє сам себе

Семантика - найбільша задача агента, тому вона йде конвеєром із п'яти скриптів:

1. **`competitors.py` - конкуренти.** На вході адреси категорій конкурентів. Скрипт бере сторінки розділу, що ранжуються (Serpstat), і фільтри зі сторінки категорії, визначає тип кожної (категорія, фільтр, товар, стаття), зводить мовні версії і показує ознаки, які повторюються в кількох конкурентів: бренди, потужність, ємність, «для котла». З `--collect` забирає ключі найсильніших фільтрів - це другий канал збору поруч із сідами.
2. **`semantic_core.py` - дерево сторінок.** Агент описує нішу в конфігу: бренди, серії й моделі, числові ознаки, призначення, тип, чужі теми і дерево рівнів (`tree`): «Бренд > Серія > Модель», «Призначення > Потужність > Тип». Скрипт кладе кожен ключ на найглибшу сторінку, яка набирає поріг (3 ключі і 50 запитів на місяць): рівень 1 - категорія, 2 - «EcoFlow», 3 - «EcoFlow > Delta», 4 - «EcoFlow > Delta > Delta 2». Дрібні сторінки розформовуються, їхні ключі піднімаються вище. Інформаційні запити окремо групуються в теми статей («Як вибрати зарядну станцію > Для квартири», «Підключення до мережі й котла»).
3. **`serp_check.py` - видача.** Детальна сторінка лишається, тільки якщо Google відповідає на неї інакше, ніж на батьківську: мало спільних адрес у топ-10 і є результати саме про уточнення. Інакше ключі зливаються з батьківською. Заразом скрипт пише, які сторінки в топі, і радить тип посадкової: категорія чи фільтр, картка товару чи лендинг моделі, стаття. Джерело - DataForSEO (живий топ) або Serpstat.
4. **`article_examples.py` - статті.** Для кожної теми статті - що у видачі і до 3 прикладів статей, спершу з сайтів конкурентів, із заголовками.
5. **`ai_review.py` - друга думка.** Кожен ключ читає ChatGPT у контексті своєї сторінки і пише, що не так: не про товар, краще на іншій сторінці, інформаційний, незрозумілий. Агент перевіряє знахідки, бо модель теж помиляється, і переносить підтверджені в правила конфігу. Решта йде тімліду з позначкою в xlsx.

Результат - один xlsx: «Кластери» з колонками рівнів і ознак, «Структура» деревом з перевіркою видачі, «Статті» з прикладами, «Інфо», «Видалено», «Конкуренти», «Зведення».

Повний конфіг прикладу: [examples/zaryadni-stantsii.config.json](examples/zaryadni-stantsii.config.json).

Скіл вмикається сам, коли задача в чаті схожа на його опис. Можна назвати його прямо: «зроби gsc-quick-wins для проєкту shop».

## Запуск

Потрібні:
- [Claude Code](https://claude.com/claude-code): десктопний застосунок або CLI, підписка Claude Pro чи вище або ключ Anthropic API;
- Python 3.10+;
- ключ Serpstat API для семантики й видачі (див. «Ключі»).

```bash
git clone https://github.com/sneex-seo/claude-code-seo-agent.git
cd claude-code-seo-agent
pip install -r requirements.txt
cp .env.example .env          # Windows: copy .env.example .env
```

Впишіть ключі в `.env`, відкрийте папку в Claude Code і напишіть у чаті, наприклад:

```
Заведи проєкт example.com.ua: інтернет-магазин кави, Україна, мови UA і RU.
```

Агент поставить уточнювальні питання, створить `clients/example/` з паспортом проєкту і далі працюватиме в його контексті. Папка `clients/` не потрапляє в git.

## Без платних API

Частина скілів працює на вивантаженнях, які у вас уже є. У `examples/` лежать синтетичні файли вигаданого магазину, на них можна перевірити агента без жодного ключа:

```
Розбери GSC: поточний період examples/gsc_current.csv, попередній examples/gsc_previous.csv.
Перевір беклінки з examples/ahrefs_backlinks.csv і підготуй disavow.
Склади анкор-план за examples/positions.csv, наявні анкори в examples/existing_anchors.csv.
```

Те саме можна запустити напряму скриптами:

```bash
python scripts/gsc_analyze.py examples/gsc_current.csv --previous examples/gsc_previous.csv --out gsc.xlsx
python scripts/link_risk.py examples/ahrefs_backlinks.csv --out links.xlsx --disavow disavow.txt
python scripts/anchor_plan.py examples/positions.csv --anchors examples/existing_anchors.csv --domain example.com.ua --out anchors.xlsx
```

## Ключі

| Змінна в `.env` | Для чого | Обов'язково |
|---|---|---|
| `SERPSTAT_TOKEN` | Семантика, топ видачі, видимість доменів, база Google Україна | Для семантики, мет, брифів, онбордингу |
| `DATAFORSEO_LOGIN`, `DATAFORSEO_PASSWORD` | Живий SERP із тайтлами, перевірка сторінок видачею (~$0.002 за запит), частотності поза Україною | Ні, запасне джерело видачі - Serpstat |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | Друга думка ChatGPT про ключі ядра, за замовчуванням gpt-4.1 | Ні |
| `SERPAPI_KEY` | Замір AI Overviews | Ні |
| `PAGESPEED_API_KEY` | Блок швидкості в тех-аудиті, ключ безкоштовний у Google Cloud | Ні |

Скільки рядків Serpstat API лишилось, показує `python scripts/serpstat_api.py limits`, цей запит безкоштовний. Перед платними прогонами (перевірка видачі, ChatGPT, AI Overviews) агент запускає `--dry-run`, називає кількість запитів і суму і чекає вашого «ок». Відповіді API кешуються в `cache/`, повторний прогін безкоштовний.

Скільки коштував приклад «зарядні станції»: Serpstat - близько 22 тис. рядків API на збір ключів і топи для перевірки видачі, ще близько 12 тис. на сторінки й ключі конкурентів; ChatGPT gpt-4.1 - $0,80 за 32 запити.

MCP-сервери Serpstat і DataForSEO необов'язкові: скіли працюють через скрипти. Щоб підключити MCP, скопіюйте `.mcp.json.example` у `.mcp.json` і впишіть ключі. Файл `.mcp.json` теж не потрапляє в git.

## Як агент здає роботу

- Результат - файл у `clients/<проєкт>/deliverables/` з датою в назві і коротке резюме: що зроблено, що видалено й чому, відкриті питання.
- У xlsx шапка жирним, автофільтр, закріплений перший рядок і підсумки груп.
- Спірні рішення агент не приймає сам: виносить списком на питання тімліду.
- Нічого не публікує, не впроваджує на сайт і не надсилає клієнту без вашого «ок».

## Обмеження

- Агент робить роботу джуна, тобто результат треба приймати і правити. Кластеризація - правила, перевірка видачею і друга модель, але спірні ключі (позначені в «Коментар») і «база» категорії потребують вашого погляду.
- Перевірка видачі наближена: рахує спільні адреси в топ-10 і результати, в адресі чи заголовку яких є ознака уточнення. Якщо в джерела немає топу за ключем, сторінка лишається з позначкою «не перевірено». Тип сторінок у видачі і в конкурентів визначається за адресою й заголовком, теж наближено.
- Деякі сайти закриті від ботів (код 403): тоді про їхню структуру є лише дані Serpstat, без назв фільтрів.
- Частотності - з бази Serpstat для Google Україна. Для інших ринків потрібен DataForSEO.
- Мінус-листи відсікають Росію, Білорусь, окуповані міста і російські платформи в будь-якій ніші. Російськомовні запити українського ринку лишаються.
- Код викладено «як є». Issues відкриті, але без обіцянок щодо строків.

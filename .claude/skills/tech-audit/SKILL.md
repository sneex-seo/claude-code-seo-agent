# Технічний аудит

Вхід: домен + бажано вивантаження краулу (Netpeak Spider / Screaming Frog, CSV/xlsx) у `clients/<проєкт>/inbox/`. Без краулу робиться «малий аудит» за ключовими URL (головна, 2-3 категорії, картка товару чи послуга, стаття), і це прямо пишеться у звіті.

## Головне правило

Кожна проблема у звіті = перевірена фактом: fetch конкретного URL, рядок краулу, відповідь API. Слова «ймовірно», «зазвичай буває» заборонені: або перевірив, або пункт іде в розділ «Потребує краулу/доступу».

## Блоки чек-листа

1. **Індексація**: robots.txt (що закрито, чи немає зайвого), sitemap.xml (існує, валідний, свіжий, вказаний у robots), meta robots і canonical на кожному типі сторінок.
2. **Відповіді й редиректи**: коди за ключовими URL (за краулом - масово), ланцюжки редиректів довші за 1 крок, склейка www/без-www і http→https, єдина політика слеша.
3. **Дублі**: Title / Description / H1 (за краулом - масово), параметричні URL, сторінки пагінації, фільтри.
4. **Швидкість**: PageSpeed Insights API, 2-3 URL різних типів: LCP, CLS, INP, топ-3 рекомендації. ⚠ Потрібен безкоштовний ключ `PAGESPEED_API_KEY` у `.env` (тімлід створює його в Google Cloud; анонімна квота API постійно вичерпана - перевірено). Ключа немає → блок позначається «потребує ключа», нічого не вигадується.
5. **Розмітка**: schema.org (Organization, BreadcrumbList, Product/Service, FAQ де доречно), OpenGraph.
6. **Мови**: пари hreflang та їхня взаємність, якщо є мовні версії.
7. **Інше**: змішаний контент HTTPS, мобільний viewport, биті внутрішні посилання (за краулом).

## Результат

`clients/<проєкт>/deliverables/<проєкт>_tech-audit_<YYYY-MM-DD>.xlsx`:

1. **Проблеми**: Пріоритет (P1-P3) | Блок | Проблема | Де (URL / маска / скільки сторінок) | Як перевірено | Рекомендація
2. **Зведення**: охоплення (краул на N сторінок / вибірково N URL), дата, кількість проблем за пріоритетами

P1 = заважає індексації або конверсії просто зараз. P1 має бути мало (до 10): це пріоритети, а не все підряд.

## Чек-лист перед здачею

- [ ] У кожному рядку заповнено «Як перевірено» з конкретикою
- [ ] Масові висновки («у 340 сторінок дубль Title») - лише з краулу; без краулу написано «вибірково, N URL»
- [ ] P1 - лише справді критичне
- [ ] Резюме: топ-5 проблем людською мовою + що потрібно для повного аудиту (краул, доступи)

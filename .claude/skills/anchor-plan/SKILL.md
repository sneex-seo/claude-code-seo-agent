# Анкор-план (зовнішні посилання)

Вхід: вивантаження позицій (Ahrefs / Serpstat / SE Ranking: URL, ключ, позиція, частотність) + бажано CSV наявних анкорів (url, anchor) - усе в `clients/<проєкт>/inbox/`.

## Кроки

1. Кандидати скриптом:
   `python scripts/anchor_plan.py "<positions.csv>" --anchors "<existing.csv>" --domain <домен> --out "clients/<проєкт>/deliverables/<проєкт>_anchors_<дата>.xlsx"`
   Скрипт сортує ключі за позицією й частотністю, ріже переспамлені (використані ≥ 5 разів) і ставить пріоритети: P1 - позиції 1-3 (захищаємо й дотискаємо), P2 - 4-10, P3 - далі.
2. **Розбав типами** (кандидати зі скрипта - «точні», це заготовка, а не готовий план):
   - точний: «купити каву в зернах»
   - розбавлений: «де купити хорошу каву в зернах»
   - брендовий: «НазваБренду», «магазин НазваБренду»
   - URL / загальний: «site.ua», «тут», «на сайті»
   Орієнтир розподілу **нових** анкорів: точні ≤ 10-15%, розбавлені 30-40%, брендові 30-40%, URL і загальні - решта. Якщо в PROJECT.md задано свій розподіл - він головніший; якщо ні - уточни в тімліда на прийманні й зафіксуй в уроках.
3. Заповни в xlsx колонку «Тип» для кожного рядка і порахуй підсумковий розподіл у «Зведенні».

## Правила

- Анкори з комерційним переспамом на сторінку, у якої й так багато точних, - в «Уникати», навіть якщо скрипт їх пропустив.
- План - це пропозиції для лінкбілдера; розміщення й донорська база - не твоя зона (поки що).
